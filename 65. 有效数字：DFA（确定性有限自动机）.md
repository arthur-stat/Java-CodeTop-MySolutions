题目简述：

> 给定一个字符串 `s` ，返回 `s` 是否是一个 **有效数字**。
>
> 例如，下面的都是有效数字：`"2", "0089", "-0.1", "+3.14", "4.", "-.9", "2e10", "-90E3", "3e+7", "+6e-1", "53.5e93", "-123.456e789"`，而接下来的不是：`"abc", "1a", "1e", "e3", "99e2.5", "--6", "-+3", "95a54e53"`。
>
> 一般的，一个 **有效数字** 可以用以下的规则之一定义：
>
> 1. 一个 **整数** 后面跟着一个 **可选指数**。
> 2. 一个 **小数** 后面跟着一个 **可选指数**。
>
> 一个 **整数** 定义为一个 **可选符号** `'-'` 或 `'+'` 后面跟着 **数字**。
>
> 一个 **小数** 定义为一个 **可选符号** `'-'` 或 `'+'` 后面跟着下述规则：
>
> 1. **数字** 后跟着一个 **小数点 `.`**。
> 2. **数字** 后跟着一个 **小数点 `.`** 再跟着 **数位**。
> 3. 一个 **小数点 `.`** 后跟着 **数位**。
>
> **指数** 定义为指数符号 `'e'` 或 `'E'`，后面跟着一个 **整数**。
>
> **数字** 定义为一个或多个数位。
>
> **提示：**
>
> - `1 <= s.length <= 20`
> - `s` 仅含英文字母（大写和小写），数字（`0-9`），加号 `'+'` ，减号 `'-'` ，或者点 `'.'` 。

题目链接：[65. 有效数字](https://leetcode.cn/problems/valid-number/)

# 原始思路

这个问题，很契合状态机的模型。定义下面的若干状态：

1. 符号 sgn，如果上一状态非 4，则下一步只能转移至 2, 3
2. 数字 num ，下一步只能转移至 2, 3, 4, 5
3. 点 dot，下一步只能转移至 2, 4, 5，且后续不得再进入 3
   - 若下一步转移至 4, 5，则要求上一步必须为 2
4. 科学计数法的指数 exp，下一步只能转移至 1, 2
   - 若下一步转移至 1，则下下一步必须转移至 2，且后续只能停留在 2，直至在某步转移至 5
   - 若下一步转移至 2，则后续只能停留在 2，直至在某步转移至 5
5. 终止状态 stop

除了 4, 5 以外，都可以作为初始状态。

其他情况均为非法。

---

想到本问题使用 DFA（Deterministic Finite Automaton，确定性有限自动机）并不困难，但一次性就考虑到所有情况、一次性编写出 AC 的算法代码，个人感觉还是没有那么容易的，需要 debug 发现未考虑齐全的边界情况。

思路是简单的，但实现起来要考虑许多边界情况，这可能是本题被标记为 HARD 的原因。

# 原始代码

算法的时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

```java
class Solution {

    private enum State {
        SGN, NUM, DOT, EXP
    }

    public boolean isNumber(String s) {
        if (s == null || s.length() == 0) return false;

        State prev = null;
        State sta = state(s.charAt(0));
        boolean dot = false;
        boolean exp = false;
        boolean exp_sgn = false;

        if (sta == null || sta == State.EXP) return false;
        
        for (int i = 0; i < s.length() - 1; i++) {
            State next = state(s.charAt(i + 1));
            if (next == null) return false;

            switch (sta) {
                case State.SGN -> {
                    if (exp_sgn) return false;
                    if (exp && exp_sgn) return false;
                    if (exp && !exp_sgn) exp_sgn = true;
                    if (next != State.NUM && next != State.DOT) return false;
                }
                case State.NUM -> {
                    if (exp) exp_sgn = true;
                    if (next == State.SGN) return false;
                }
                case State.DOT -> {
                    if (dot) return false;
                    if (exp) return false;
                    if (next == State.SGN || next == State.DOT) return false;
                    if (next == State.EXP && prev != State.NUM) return false;
                    dot = true;
                }
                case State.EXP -> {
                    if (exp) return false;
                    exp = true;
                }
            }

            prev = sta;
            sta = next;
        }

        // last == sta
        if (sta == null || sta == State.SGN || sta == State.EXP) return false;
        if (sta == State.DOT && prev != State.NUM) return false;
        if (sta == State.DOT && (dot || exp)) return false;

        return true;
    }

    private State state(char c) {
        if (c == '+' || c == '-') return State.SGN;
        if (c >= '0' && c <= '9') return State.NUM;
        if (c == '.') return State.DOT;
        if (c == 'e' || c == 'E') return State.EXP;
        return null;
    }
}
```

# 反思

其实状态可以定义得更自然、干净一点，这样可以避免为状态设计额外的记忆：

```
START         // 初始状态
SGN           // 符号状态（+/-）
NUM           // 整数部分数字
DOT_AFTER_NUM // 数字后的点
DOT_NO_NUM    // 点前无数字
DOT_WITH_NUM  // 点后有数字
EXP           // 指数符号（E/e）
EXP_SGN       // 指数部分的符号
EXP_NUM       // 指数部分的数字
STOP          // 终止状态
```

这样就不需要那么麻烦的条件。也不必考虑那么复杂的边界情况。

          │      │
          │      ├── DOT → DOT_AFTER_NUM ──NUM──→ DOT_WITH_NUM
          │      │       │                          │
          │      │       └── EXP ───────────────→ EXP
          │      │                                  │
          │      └── EXP → EXP                      │
          │                                         │
          └── DOT → DOT_NO_NUM ──NUM──────────────→ DOT_WITH_NUM

EXP ──NUM──→ EXP_NUM ──NUM──→ EXP_NUM
 │
 └── SGN ──→ EXP_SGN ──NUM──→ EXP_NUM

DOT_WITH_NUM ──NUM──→ DOT_WITH_NUM
      │
      └── EXP ──→ EXP

# 改进代码

算法的时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

```java
class Solution {

    private enum State {
        START,         // 初始状态
        SGN,           // 符号状态（+/-）
        NUM,           // 整数部分数字
        DOT_AFTER_NUM, // 数字后的点
        DOT_NO_NUM,    // 点前无数字
        DOT_WITH_NUM,  // 点后有数字
        EXP,           // 指数符号（E/e）
        EXP_SGN,       // 指数部分的符号
        EXP_NUM,       // 指数部分的数字
        STOP           // 终止状态
    }

    public boolean isNumber(String s) {
        if (s == null || s.length() == 0) return false;

        State sta = State.START;

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            
            switch (sta) {
                case START -> {
                    if (isSign(c)) sta = State.SGN;
                    else if (isDigit(c)) sta = State.NUM;
                    else if (isDot(c)) sta = State.DOT_NO_NUM;
                    else return false;
                }
                case SGN -> {
                    if (isDigit(c)) sta = State.NUM;
                    else if (isDot(c)) sta = State.DOT_NO_NUM;
                    else return false;
                }
                case NUM -> {
                    if (isDigit(c)) sta = State.NUM;
                    else if (isDot(c)) sta = State.DOT_AFTER_NUM;
                    else if (isExp(c)) sta = State.EXP;
                    else return false;
                }
                case DOT_AFTER_NUM -> {
                    if (isDigit(c)) sta = State.DOT_WITH_NUM;
                    else if (isExp(c)) sta = State.EXP;
                    else return false;
                }
                case DOT_NO_NUM -> {
                    if (isDigit(c)) sta = State.DOT_WITH_NUM;
                    else return false;
                }
                case DOT_WITH_NUM -> {
                    if (isDigit(c)) sta = State.DOT_WITH_NUM;
                    else if (isExp(c)) sta = State.EXP;
                    else return false;
                }
                case EXP -> {
                    if (isSign(c)) sta = State.EXP_SGN;
                    else if (isDigit(c)) sta = State.EXP_NUM;
                    else return false;
                }
                case EXP_SGN -> {
                    if (isDigit(c)) sta = State.EXP_NUM;
                    else return false;
                }
                case EXP_NUM -> {
                    if (isDigit(c)) sta = State.EXP_NUM;
                    else return false;
                }
                default -> {
                    return false;
                }
            }
        }

        return sta == State.NUM || 
               sta == State.DOT_AFTER_NUM || 
               sta == State.DOT_WITH_NUM || 
               sta == State.EXP_NUM;
    }

    private boolean isDigit(char c) {
        return c >= '0' && c <= '9';
    }

    private boolean isSign(char c) {
        return c == '+' || c == '-';
    }

    private boolean isDot(char c) {
        return c == '.';
    }

    private boolean isExp(char c) {
        return c == 'e' || c == 'E';
    }
}
```
