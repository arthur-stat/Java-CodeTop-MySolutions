题目简述：

> 给你一个非空数组，返回此数组中 **第三大的数** 。如果不存在，则返回数组中最大的数。

题目链接：[414. 第三大的数](https://leetcode.cn/problems/third-maximum-number/)

# 思路

动态地维护已知的前三大数即可，注意避免记录重复值。

# 代码

算法的时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

```java
class Solution {
    public int thirdMax(int[] nums) {
        Integer a = null;
        Integer b = null;
        Integer c = null;

        for (int num : nums) {
            if (a == null || num > a) {
                c = b;
                b = a;
                a = num;
            } else if (num == a) {
                continue;
            } else if (b == null || num > b) {
                c = b;
                b = num;
            } else if (num == b) {
                continue;
            } else if (c == null || num > c) {
                c = num;
            }
        }

        return c == null ? a : c;
    }
}
```
