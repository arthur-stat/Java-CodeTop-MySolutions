题目简述：

> 给定一组 `n` 人（编号为 `1, 2, ..., n`）， 我们想把每个人分进**任意**大小的两组。每个人都可能不喜欢其他人，那么他们不应该属于同一组。
>
> 给定整数 `n` 和数组 `dislikes` ，其中 `dislikes[i] = [ai, bi]` ，表示不允许将编号为 `ai` 和 `bi`的人归入同一组。当可以用这种方法将所有人分进两组时，返回 `true`；否则返回 `false`。

题目链接：[886. 可能的二分法](https://leetcode.cn/problems/possible-bipartition/)

# 思路

图的二分问题，考虑染色标记，BFS 或 DFS 均可。对于索引为 `i` 的人，他被分在一组，则他不喜欢的人必须全部在另一组。用图论的模型讲，一个节点的所有邻居必须与该节点分别位于两组，因此进行一次图的遍历即可，检查是否可以达成该要求。BFS 还是 DFS 是无关紧要的。

**本问题的重点是三色标记，必须使用三状态区分未到达、第一类与第二类。**

下文还会记录一个错误思路，未考虑 DFS / BFS，且只使用了两状态。

# 代码

算法的时间复杂度为 $O(V+E)$，空间复杂度为 $O(V+E)$。

```java
class Solution {
    public boolean possibleBipartition(int n, int[][] dislikes) {
        List<Set<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < n; i++) adj.add(new HashSet<>());
        for (int j = 0; j < dislikes.length; j++) {
            int a = dislikes[j][0] - 1;
            int b = dislikes[j][1] - 1;
            adj.get(a).add(b);
            adj.get(b).add(a);
        }

        int[] state = new int[n];
        Deque<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (state[i] != 0) continue;
            state[i] = 1;
            q.offer(i);
            int m = 1;
            int bfs_sign = -1;

            while (!q.isEmpty()) {
                int j = q.poll();
                m--;

                for (int k : adj.get(j)) {
                    if (state[k] == 0) {
                        q.offer(k);
                        state[k] = bfs_sign;
                    } else if (state[k] == -bfs_sign) {
                        return false;
                    }
                }
                
                if (m == 0) {
                    m = q.size();
                    bfs_sign = -bfs_sign;
                }
            }
        }

        return true;
    }
}
```

记录一个错误思路，没有区分首次到达与已分类，按节点编号顺序局部扩张而非 DFS / BFS 遍历，会把尚未确定连接关系的连通分量分别染色，因此这部分后来通过边连接时，无法再整体翻转其中一个分量。

        Set<Integer> v = new HashSet<>();

        for (int i = 0; i < n; i++) {
            Set<Integer> set = adj.get(i);

            if (u.contains(i)) {
                if (Collections.disjoint(u, set)) return false;
                u.add(i);
                v.addAll(set);
            }

            else if (v.contains(i)) {
                if (Collections.disjoint(v, set)) return false;
                v.add(i);
                u.addAll(set);
            }

            else {
                u.add(i);
                v.addAll(set);
            }
        }

        return true;
    }
}
